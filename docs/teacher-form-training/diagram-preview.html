Teacher-Info Form App — Build with Claude (React + Microsoft Graph)

Non-technical learners build this by prompting Claude. Data lands in an Excel table on OneDrive/SharePoint.

App architecture & data flow

Sign in with Microsoft, submit the form, Graph writes a row to the Excel table.

flowchart TD
    Teacher(["Teacher (M365 user)"])
    subgraph App["React app (Vite) - built by prompting Claude"]
        Form["Teacher info form"]
        MSAL["MSAL sign-in<br/>@azure/msal-react"]
        GraphCall["Graph API call<br/>add row to table"]
    end
    Entra["Microsoft Entra ID (Azure AD)<br/>app registration + Graph permissions"]
    Graph["Microsoft Graph API"]
    Excel[("Excel workbook table<br/>on OneDrive / SharePoint")]

    Teacher -->|opens app| Form
    Teacher -->|sign in| MSAL
    MSAL <-->|"auth + access token"| Entra
    Form -->|submit| GraphCall
    GraphCall -->|"token + POST rows/add"| Graph
    Graph -->|writes row| Excel
